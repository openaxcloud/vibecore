# Status Page

The public status page should expose:

- API
- Dashboard
- IDE
- Workspace runtime
- Preview proxy
- AI Gateway
- Billing
- Deployments
- Collaboration

## Automation

Status should be driven by:

- uptime checks
- synthetic checks
- SLO alerts
- manual incident updates

## User Communication

For SEV1 and SEV2:

- acknowledge within 10 minutes
- update every 30 minutes
- publish resolution summary
- publish postmortem for material incidents
