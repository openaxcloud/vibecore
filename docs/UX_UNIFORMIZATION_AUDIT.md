# Audit d'uniformisation UX/UI — IDE VibeCore/E-Code

Date : 2026-08-24 · Base : `origin/main` @ `f1f03057` (worktree `chore/ide-ui-uniformization`)
Méthode : lecture de code + greps (pas de vérification à l'écran — la validation visuelle finale reste à faire en live par Avi).
Fichier central : `app/components/chat/BaseChat.tsx` (23 275 lignes — l'IDE entier y vit, y compris ~25 panneaux inline).

## 0. Architecture constatée (pour comprendre les incohérences)

- Les panneaux « gestion » (Overview, Database, Deployments, Git, Secrets, Monitoring, Settings, Packages, Skills, Integrations, Workflows, Debugger, Extensions, Snapshots, Security, Activity, Collaborators, Logs, Ports, Domains, Object Storage, Env, Studio) passent tous par **une coque commune** `ProjectIdeApiServicePanel` (BaseChat.tsx:10443) qui rend l'en-tête partagé `.bolt-project-ide-panel-header` (BaseChat.tsx:10832-10884) : icône + titre + puce « Updated … » + menu ⋮ (Refresh / cadence).
- Les panneaux « workspace » (Editor, Files, Search, Locks, Preview/Webview, Terminal, Problems) **court-circuitent cette coque** (BaseChat.tsx:7675-7847) : chacun a sa propre tête (ou pas de tête du tout). C'est la source n°1 du ressenti « chaque panneau est différent ».
- Il existe DÉJÀ des composants partagés sous-utilisés : `ui/EmptyState` (canonique, doc DESIGN_ACCENTS), `ui/PanelHeader` (utilisé par le workbench seulement), `ui/Button`, `ui/IconButton`. Les panneaux de BaseChat ont leurs propres primitives locales (`PanelButton`, `PanelInput`, `PanelRows`, BaseChat.tsx:23002-23059) qui dupliquent — et divergent de — celles d'`ui/`.

## 2. Système cible (composants partagés)

1. **`PanelPrimitives`** (`app/components/project-ide/PanelPrimitives.tsx` — créé au lot 1) : `PanelButton` (respecte `type`, variantes primary/outline), `PanelInput`, `PanelEmptyState` (enrobe le `ui/EmptyState` canonique en variante compacte). Exportés et testés — plus de primitives privées dans BaseChat.
2. **`IdePanelHeader` unique** : fusionner `.bolt-project-ide-panel-header` (36 px) et `ui/PanelHeader` (34 px) en un composant : icône + titre + slot « meta » (Updated/compteurs) + slot actions (⋮). Adopté par Problems, Search, Locks, Files ensuite.
3. **`PanelSectionTitle`** : 2 niveaux (section 13 px semibold / groupe 11 px uppercase).
4. **Registre unique `PANEL_META`** : `{ id, title, icon, description, group }` consommé par onglets, rail, palette « + », tuiles mobile (fin des 3 tables divergentes).
5. **Tokens** : échelle typo fermée (11/12/13/14), rayon unique 8 px pour les contrôles, hauteurs de contrôle 28 px (onglet) / 32 px (composeur, header) / 36 px (formulaires), statuts sur `--vc-ide-accent-*`.
