## Alerte marge négative BLOQUANTE — brouillon avec revient economy = 100000 ¢/M :
POST /admin/agent-routing (sans confirmNegativeMargin)
  → HTTP 409 {"error":"Negative margin on: economy. Confirm explicitly to publish anyway.",
              "code":"AGENT_ROUTING_NEGATIVE_MARGIN","negativeLines":["economy"]}
  → la carte active v1 reste intacte (publication refusée).

  → {"windowDays":30,"negativeLines":["economy"],"totals":{...}}  (répond, volume réel rejoué)
