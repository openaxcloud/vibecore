## HONEST UX NOTE (product gap)
  The IDE's own top-right 'Publish' button opens the IDE Deployments PANEL whose
  provider list (BOLT_DEPLOY_PROVIDERS in app/components/deploy/deployUtils.ts) is
  static + external only: Static export, Vercel, Netlify, GitHub Pages, Cloudflare
  Pages, Google Cloud Run, Custom Dockerfile — NO internal 'server' option.
  Our server-deploy (provider='server') is only reachable from the project
  Deployments PAGE (/projects/<id>/deployments, linked from the Dashboard 'Deploy'
  CTA), which is where the Publish above was clicked. The IDE Publish button and the
  Dashboard deploy page are two different surfaces; the server path lives only on the
  latter. Worth unifying.
