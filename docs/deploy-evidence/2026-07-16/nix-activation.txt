# Nix v2 toolchain auto-activation — python/uv/go on PATH with zero setup (2026-07-16, fix 83459fff)

## The gap
The gen-2 Nix store ships a signed catalog (/nix/ecode/catalog.json: nix 2.34.8,
nixpkgs nixos-26.05) mapping each runtime to a profile bin with python3/pip/uv/
virtualenv/go — but NO code put them on the workspace PATH. So on a nix workspace,
bare 'uv'/'python3' resolved to nothing (alpine base has neither); PY-PREVIEW-01
only worked because I hand-munged the venv path.

## The fix (services/workspace-agent/src/app.ts, commit 83459fff)
sanitizedChildEnv (the common env for terminals + run_command + streamed dev
servers) now APPENDS the catalog's profile bin dirs to PATH: base tools (node/npm)
keep priority, nix ADDS the runtimes the base lacks. Cached once; inert when /nix
absent. Unit tests: nixToolchainBinDirs (catalog parse + missing-profile skip).
