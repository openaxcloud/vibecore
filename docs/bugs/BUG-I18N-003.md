## Bug

**P2 — le PLAN de l'agent s'affiche en ANGLAIS dans une interface française**, sur les 3 formats. Les libellés de voie sont bien traduits (ARCHITECTE, INTERFACE UTILISATEUR, SERVICE APPLICATIF, DEVOPS, QA) mais **les descriptions générées le sont en anglais** : « Define system architecture, component hierarchy, data models, state boundaries, and routing structure for **French-language** React app », « Build complete UI with dark/light mode toggle, mobile-first responsive layouts… », « Create Vite config, package.json with dev script… », « Write tests for critical workflows… ». Le modèle sait donc que l'application doit être en français — il l'écrit — mais rédige quand même le plan en anglais. À distinguer d'une traduction manquante : **le catalogue FR existe** (`app/lib/i18n/catalogs/api-chat.ts:147+` : « Définir l'architecture du système, le modèle de données, les contrats API… ») et sert de valeur par défaut ; ce qui s'affiche est du texte **produit par le LLM**, pas le catalogue. Le correctif est donc côté **prompt d'orchestration** (`app/lib/.server/llm/agent-orchestration.ts`, `ECODE_AGENT_ROLES`), qui n'impose pas la langue de sortie du plan.
