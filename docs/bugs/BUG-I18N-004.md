## Bug

**P3 — l'état d'un port s'affiche « commencer » en français : le VERBE à l'infinitif là où l'anglais met un ÉTAT.** Dans le panneau Ports, un port en cours de démarrage est étiqueté `:5173 **commencer**` — sur un badge de statut (`--status-warning-text`), juste à côté de son pendant correct « prêt ». Le rendu est binaire (`BaseChat.tsx:17486` : `entry.ready ? t('…ready_75c05337') : t('…starting_9493af05')`), donc l'anglais `starting` a été traduit comme le verbe « commencer » au lieu de l'état « démarrage ». Artefact de traduction automatique — le nom de clé lui-même (`starting_9493af05`, suffixé d'un hash) trahit une extraction automatique. Le reste du dépôt traduit pourtant cet état correctement par « **démarrage** » dans **4 autres catalogues** (`admin.route.statusStarting`, `admin.standalone.status.starting`, `baseChatAst.status.starting`, `projectDashboard.status.starting`).
